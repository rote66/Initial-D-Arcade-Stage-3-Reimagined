# Chinese UI fonts

Noto Sans CJK SC Regular and TC Regular from the official Noto CJK project:

- https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese
- https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/TraditionalChinese

Distributed under the SIL Open Font License 1.1; see `NotoSansCJK-OFL.txt`.
These original, unmodified fonts include all Chinese characters in the reviewed
UI catalog. SC and TC keep their respective regional glyph forms. They belong
to the core application, so updating UI translations does not change game data.
