# 说明

当前版本使用 Unity 6.6（6000.6.4f1）、IL2CPP 和静态 C++ 核心，目标为 iOS 15.0 及以上的 ARM64 iPhone/iPad。运行不需要 JIT。主要面向自签、TrollStore 和越狱设备；生成的是 `codesign --sign -` 的 ad-hoc 签名 IPA，无开发者证书和 provisioning profile，不是苹果开发者账号的 Ad Hoc 分发包。

开发、同步上游、验证和提交约定见 [AGENTS.md](AGENTS.md).

## iOS端已有特性

- 双人局域网对战（未测试）；Steam、EOS 公网匹配、Discord 和自动检查更新在 iOS 版禁用。
- 模拟器式触控摇杆，默认数字踏板按下即满油门/满刹车。设置 → iOS → 滑动行程默认关闭，开启后支持直接点按和上下滑动，底部 0%、中间 50%、顶部 100%，踏板按比例点亮。仅在勾选滑动行程时显示顶部／底部死区，各默认 0%、范围 0–40%、步进 1%，按整个按钮高度计算；顶部 5% 表示距顶部 5% 即满量程，底部 5% 表示进入底部 5% 即归零，中间剩余行程线性映射。死区下方的“仅油门滑动行程”“仅刹车滑动行程”互斥，都不勾选则两个都是滑动行程；选中一个后另一个保持数字满量程。关闭总开关保留死区和选择。
- 布局编辑预览仍可调整全部现存控件，隐藏不改保存位置。菜单摇杆上下仍可换车色和切换车型榜；VIEW 保留视角、标题长按设置与排行榜功能。
- 标题／开场界面长按 VIEW（相机图标）约 0.65 秒进入原版设置；比赛中按 START 暂停后进入选项。触控布局可拖动调整、保存、恢复默认和导出 JSON。
- 可随时开关重力转向，并调整死区和灵敏度。
- 自定义菜单与原版文字均支持英/日/简中，分别设置；原版文字语言应用后需重启。菜单初次按设备语言选择，繁体设备使用简中。按键图案保持符号。
- OSD 显示 FPS、进程 CPU、GPU 和 RAM（MiB）。RAM 是应用的实际内存占用。OSD 与原版“显示帧率”共享主相机渲染统计，每约 0.5 秒更新；不是固定 60 Hz 的模拟逻辑计数。GPU 无可用测量时显示 `--`。
- 设置 → iOS → 生成诊断日志，默认关闭，点击“应用”后才启停。开启后后台写入 `Documents/Diagnostics`；取消勾选并应用后停止写入并删除生成的日志，其他用户文件保留。
- 设置 → iOS → 禁用温度帧率调整，默认不勾选（调整开启），勾选并应用后关闭调整。旧存档保留原来的实际启用状态，只反转界面勾选含义。应用禁用后取消 Unity 的 Serious=30 / Critical=15 帧率上限；显式帧率设置与 iOS 自身的热管理仍然生效。
- 上游无损压缩用于 native 模型／纹理和 Unity 资源，运行时直接读取，不在 Documents 解压还原；原始资源不改。
- 一个 core IPA 同时读取完整原音频数据和精简 MP3 数据，完整内容需与版本匹配；打包精简时 117 首音乐的精简版为 192 kbps MP3。
- 固定 Bundle ID：`org.idas3.reimagined.ios`；代码通过系统解析路径，不依赖容器 UUID。

汉化风格参考 PSP《头文字D 公路传说》汉化版，参考补丁来源于 [retro.libfun.de](https://retro.libfun.de/initial_d/)。剧情按 D3 街机原文独立翻译，汉化图像自行排字制作。

## 局域网联机（未实机测试）

1. 两台设备安装相同版本的 IPA 和相同的赛道数据，连接同一 Wi-Fi。
2. 标题界面长按 VIEW → **网络** → **局域网联机**（比赛中也可由 START → 选项进入）。首次连接时允许系统的“本地网络”权限；拒绝后可在 iOS 设置中重新允许。
3. 一方选择“创建房间”，另一方选择“输入地址加入”，填写房主显示的 `IPv4:端口`，如 `192.168.1.20:27035`。可点“编辑”使用内置数字键盘。
4. 双方选择车辆与赛道并点“准备”，由房主点“开始比赛”。系统随机采用其中一方的完整赛道设置。

目前只支持双人手动直连，没有自动发现、Steam 房间或公网匹配。访客 Wi-Fi、AP 隔离等会阻止设备互通。大厅内隐藏驾驶虚拟键，可直接点按各项操作；比赛中通过 START 打开暂停／比赛菜单，再由选项进入网络。断线后本场不记成绩和点数，确认后回到菜单。

版本兼容使用构建时生成的代码/原始物理数据指纹，并校验扩展赛道的路径和碰撞数据，避免不同模拟逻辑混用。此次开放的是同版本 iOS 设备之间的联机，不承诺与原 Windows/Steam 版本互通。

社区计时榜使用独立 HTTP 服务，不依赖 Steam/EOS 联机。保留“社区计时”开启且设备能联网时，仍可下载社区成绩；关闭该设置或断网后使用个人本地成绩。下载快照需要近期在线确认（75 秒），不会永久离线使用缓存；比赛开始时已捕获的成绩保持到该场结束。

## 数据导入

core IPA 不包含大数据。安装后启动一次，在“文件”中进入“我的 iPhone / Initial D Arcade Stage3 Reimagined”，将 ZIP 放到应用 Documents，再用应用内导入功能安装。

如在电脑解压后用itunes传输，应把整个 `IDAS3GameData` 文件夹放到应用的 Documents 下，使 `Documents/IDAS3GameData/game-data.json` 直接存在。不要重复嵌套同名目录。手工升级应替换整个数据目录，避免覆盖合并留下旧音乐；保留同级存档、布局和自定义音乐。更新 IPA 时尽量覆盖安装，避免卸载。

## 编译 IPA

需要 macOS、已完成初始化的 Xcode、Unity 6.6 的 iOS Build Support、CMake、Python 3.11+、FFmpeg/FFprobe。Unity 编辑器的默认位置见构建脚本，可通过 `--unity` 或 `IDAS3_UNITY_EDITOR` 指定。

在项目根目录执行：

```bash
# 默认：通用 core IPA + 精简 MP3 数据包
./build-ios.sh
./build-ios.sh core-small

# 通用 core IPA + 完整原音频数据包
./build-ios.sh core-full

# 所有数据内嵌的完整 IPA（体积和构建磁盘占用较大）
./build-ios.sh full
```

## 清理构建

```bash
./build-ios.sh --clean --dry-run  # 预览
./build-ios.sh --clean            # 清理后退出，不构建
```

清除设备/模拟器 Xcode 导出、DerivedData、MP3 转码和 native LZ4 缓存、iOS native 构建目录，以及 Unity 的 Bee、PlayerDataCache、BuildHistory。保留 IPA、数据 ZIP、验证报告、日志、源码、设备插件 archive 和所有存档；不删除系统 Simulator runtime，也不卸载模拟器内应用。下次构建会重新生成缓存，包含重新转码音乐的时间。

只清设备导出可执行 `python3 Tools/Clean-iOS.py device`；只清模拟器导出可执行 `python3 Tools/Clean-iOS.py simulator`。
